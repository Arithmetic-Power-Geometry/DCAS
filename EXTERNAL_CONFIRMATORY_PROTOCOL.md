# Frozen external CEC and contemporary-SOTA confirmatory protocol

**Freeze point.** The DCAS core, action availability rule, structural burden, credit definition and default hyperparameters are fixed before external results are inspected.

**Primary endpoint.** Feasibility-first matched rank under the official evaluator and official evaluation budget. No raw objective is averaged across heterogeneous functions.

**Suites.** CEC 2010 constrained, CEC 2017 constrained, CEC 2020 constrained, and the CEC-2025 BC-CSOP track where an official/public competition package is available. The generated job manifest records dimensions, seeds and budget before execution.

**Primary released comparator.** RDEx-CSOP from its public author repository. Other systems (DRL-AEOSF, constraint-consensus, ARCH/CMA-ES, SHADE/L-SHADE/JADE) are included only when a verified public implementation and documented runner are available. Missing author code is recorded as not executed; it is never replaced by an imitation and labeled as author code.

**Runs.** Use the competition-specified number of independent runs, dimensions, tolerances, and evaluation budget for each suite. If a suite does not prescribe a value, the manifest uses an explicitly declared fallback and labels it as non-official. DCAS is not retuned after external outcomes are visible.

**Statistics.** Friedman omnibus, Holm-corrected paired tests, Vargha-Delaney A12, win/tie/loss, success rate, final violation, final objective, EFF, runtime, ECDF, and performance profiles. Official competition metrics are reported in addition to—not instead of—the common analysis.

**Claim rule.** A global SOTA statement is permitted only if direct released-code comparisons under official protocols support it. Otherwise results are reported exactly as competitive, mixed, or inferior.
